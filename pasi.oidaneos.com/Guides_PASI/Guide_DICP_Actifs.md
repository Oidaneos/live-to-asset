# Guide Méthodologique : Classification des Actifs SI & Matrice DICP

## 1. Objectif de la démarche (Compétence C1)
L'état des lieux du Système d'Information repose sur la capacité à identifier précisément les actifs et à évaluer leur criticité selon la grille universelle **DICP** :

- **D - Disponibilité** : L'actif doit-il être accessible sans interruption ?
- **I - Intégrité** : Les données ou processus peuvent-ils être altérés sans détection ?
- **C - Confidentialité** : Répercussions d'une fuite d'informations sensibles (RGPD, secrets d'affaires).
- **P - Preuve / Traçabilité** : Imputabilité certaine des actions réalisées sur l'actif.

---

## 2. Échelle de Cotation (1 à 4)
| Niveau | Impact Opérationnel | Exemples |
| :---: | :--- | :--- |
| **1 - Faible** | Gêne mineure, travail dégradé simple | Site vitrine |
| **2 - Moyen** | Retard de production, coût modéré | Messagerie interne |
| **3 - Élevé** | Arrêt facturation, risque légal | Logiciel de paie / ERP |
| **4 - Critique** | Survie menacée, arrêt total | Base de production, Active Directory |
